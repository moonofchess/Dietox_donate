# Dietox — 치지직 후원 차단

후원을 끊고 싶은 사람이 자기 폰에 직접 설치해서 쓰는 안드로이드 앱입니다.
치지직 앱의 **후원 버튼을 덮개로 가리고**, **치즈 충전·결제 화면에 들어가면 되돌립니다.**
그리고 지르고 싶은 순간에 스스로 차단을 꺼버리지 못하도록 **기간 잠금**을 걸 수 있습니다.

## 어떻게 막는가

후원까지 가는 길목을 세 군데에서 끊습니다.

| 지점 | 동작 | 이유 |
|---|---|---|
| 방송 화면의 후원 버튼 | 그 자리에 덮개를 씌워 터치를 삼킴 | 버튼이 뜬다고 화면을 되돌리면 방송을 볼 수가 없다 |
| 후원 시트 (금액·메시지 입력) | 뒤로 되돌리고 안내 표시 | 여기까지 왔으면 이미 후원 흐름이다 |
| 치즈 충전·결제 화면, 구글 플레이 결제창 | 뒤로 되돌리고 기록 | 마지막 방어선 |

핵심은 **덮기와 되돌리기를 구분한 것**입니다. 후원 버튼은 방송 화면에 항상 떠 있기 때문에,
버튼이 보인다는 이유만으로 뒤로가기를 눌러버리면 방송 시청 자체가 불가능해집니다.
그래서 상주하는 버튼은 가리기만 하고, 되돌리기는 실제로 후원·결제 화면에 진입했을 때만 합니다.

채팅에 흘러나오는 남의 후원 알림(`OOO님이 1,000 치즈 후원!`)도 마찬가지 이유로
판정 전에 걸러냅니다. 이 필터가 없으면 방송을 보는 것만으로 차단이 걸립니다.

## 기간 잠금

후원을 끊는 데 실제로 걸리는 건 차단 기능이 아니라, **지르고 싶은 순간에 사람이 설정을 열어
차단을 꺼버린다는 점**입니다. 그래서 기간을 정해 잠그면 그동안은 본인도 풀 수 없습니다.

- 잠금 중: 차단 끄기 ✗ · 감시 앱 빼기 ✗ · 기간 줄이기 ✗
- 잠금 중에도: 감시 앱 추가 ✓ · 기간 늘리기 ✓
- `설정 앱 접근 막기`를 켜두면, 잠금 중 접근성 설정으로 들어갈 때 홈 화면으로 되돌립니다

예외 통로는 일부러 두지 않았습니다. 비밀번호로 푸는 문을 만들면 그 문으로 나갑니다.

## 설치

APK는 GitHub이 빌드해서 올려 줍니다. 안드로이드 스튜디오도, PC도 필요 없습니다.

**폰에서 바로 받기 (가장 쉬움)**

폰 브라우저 주소창에 이것만 치면 바로 받아집니다. GitHub 페이지를 거치지 않습니다.

```
github.com/moonofchess/Dietox_donate/releases/latest/download/dietox.apk
```

받은 뒤 "이 출처의 앱 설치를 허용" 을 켜 달라고 하면 켜 주고 설치하면 됩니다.
버전이 붙은 파일이 필요하면 [Releases](../../releases) 페이지에 함께 올려 둡니다.

릴리스가 아직 없다면 **Actions** 탭 → `Release APK` → `Run workflow` 를 눌러
버전을 적고 실행하면 몇 분 뒤에 생깁니다. 태그를 밀어도 똑같이 동작합니다.

```bash
git tag v1.0.1 && git push origin v1.0.1
```

**직접 빌드하려면**

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 첫 설정

앱을 열면 **준비하기** 항목이 셋 뜹니다. 전부 채워야 동작합니다.

1. **접근성 권한** — 설정 › 접근성 › `Dietox 후원차단` 켜기
2. **다른 앱 위에 표시** — 덮개를 그리는 데 필요
3. **감시할 앱** — 목록에서 치지직을 고른다 (`치지직으로 보임` 표시가 붙은 앱이 위에 나옵니다)

그다음 잠금 기간을 고르면 끝입니다. 처음이라면 1주 정도로 시작해서 늘려 가는 편이 낫습니다.

## 솔직하게 밝히는 한계

- **앱을 지우면 뚫립니다.** 안드로이드에서 앱 삭제를 완전히 막을 방법은 없습니다.
  잠금 중 설정 접근을 막는 건 충동을 늦추는 장치지, 물리적인 벽이 아닙니다.
- **문구를 보고 판단합니다.** 치지직이 업데이트로 문구를 바꾸면 놓칠 수 있습니다.
  그럴 땐 [`Keywords.kt`](app/src/main/java/com/dietox/donate/detect/Keywords.kt) 에 문구를 추가하면 됩니다.
- **안드로이드 전용이고, PC 웹은 막지 않습니다.**
- **테스트용 서명 APK입니다.** 빌드마다 서명 키가 달라지므로, 다음 버전을 설치할 때
  기존 앱을 먼저 지워야 할 수 있습니다.
- **실제 치지직 앱에서의 동작은 아직 확인되지 않았습니다.** 판정 로직은 단위 테스트로 검증했지만,
  실기기에서 치지직을 상대로 돌려본 적은 없습니다. 처음 며칠은 잠금을 짧게 걸고 실제로 막히는지
  확인해 보세요. 안 막히는 화면이 있으면 그 화면의 문구를 `Keywords.kt` 에 넣으면 됩니다.

## 같이 해두면 좋은 것들

앱만으로는 부족합니다. 결제 수단 자체를 끊는 쪽이 훨씬 확실합니다.

- 치지직·네이버페이에 등록된 **카드를 삭제**한다
- 구글 플레이 › 설정 › 인증 › **모든 구매에 인증 요구**를 켠다
- 통신사 고객센터에서 **소액결제를 차단**한다
- 안드로이드 **디지털 웰빙**에서 치지직 앱 사용 시간에 제한을 건다

돈이 많이 나가고 있고 스스로 조절이 잘 안 된다고 느끼면,
한국도박문제예방치유원 **1336** (24시간, 무료)에서 상담받을 수 있습니다.
후원 과소비도 상담 대상입니다.

## 개인정보

- 화면에서 읽은 내용은 **판정에만 쓰고 저장하지 않습니다.**
- 네트워크 권한이 없습니다. 기기 밖으로 나가는 데이터가 없습니다.
- 저장하는 건 설정값과 차단 횟수뿐이고, 전부 기기 안에 있습니다.

## 구조

```
app/src/main/java/com/dietox/donate/
├── detect/         화면 판정 — 안드로이드 의존 없는 순수 로직
│   ├── Keywords.kt          문구 목록 (여기만 고치면 대응 가능)
│   └── DonationDetector.kt  덮기 / 되돌리기 / 통과 판정
├── lock/SelfLock.kt         기간 잠금 규칙
├── service/                 접근성 서비스
├── overlay/                 덮개와 안내 창
├── data/                    설정·기록 저장
└── ui/                      화면
```

판정과 잠금 규칙은 안드로이드에 의존하지 않게 떼어 놓았습니다.
그래서 `./gradlew test` 로 실기기 없이 검증할 수 있고, CI에서도 매번 돌아갑니다.
